# 酒田道場

酒田五法のローソク足パターンを学べるiOSクイズアプリです。

## 概要

日本株の相場分析で古くから使われる「酒田五法」のチャートパターン42種を、繰り返しクイズ形式で学習できます。相場の転換サインを素早く見抜く力を身につけることを目的としています。

## 機能

### クイズモード
- **上昇／下落**: チャートを見てその後の方向を当てる
- **パターン名4択**: ローソク足の形からパターン名を選ぶ
- **基本形 / 実戦**: 模式図チャートと実際の日本株市場チャートを切り替え
- **問題数**: 10問 / 30問 / 無制限

### 学習サポート
- **デイリーチャレンジ**: 1日1回、全員共通の5問（実戦チャート・パターン名4択）に挑戦。連続日数を記録し、結果をWordle風に共有できる
- **弱点強化モード**: 間違えたパターンが優先的に出題される（50問ミスで解放）
- **連続正解ストリーク**: 何問連続で正解できるかを記録
- **進捗バー**: クイズ中の進捗を視覚的に表示

### パターン図鑑
- 全42パターンを「方向別（上昇・下落）」「分類別（三山・三川など）」「名前順」で並べ替えて一覧表示
- 各パターンの模式図チャート・説明・実例チャートを確認できる
- 苦手なパターンには炎アイコンで表示

## 技術スタック

- Swift / SwiftUI
- iOS 26.2+
- yfinance（クイズデータ生成、Pythonスクリプト）

## クイズデータの生成

`generate_quiz.py` を使って日本株の過去データから各パターン最大500件のチャートデータを生成します。

```bash
pip install yfinance pandas requests openpyxl
python generate_quiz.py                      # 全パターンを生成
python generate_quiz.py --only 三尊 逆三尊   # 指定したパターンだけ生成（他のJSONは変更しない）
```

パターンごとのJSONが `SakataChartQuiz/patterns/` に書き出されます。パターンを追加・改名したときは、`PatternCatalog.swift`（一覧・分類・旧IDの移行）、`PatternLocalization.swift`、`IdealPatterns.swift` も合わせて更新してください。
