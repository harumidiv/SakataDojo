# 酒田道場

酒田五法のローソク足パターンを学べるiOSクイズアプリです。

## 概要

日本株の相場分析で古くから使われる「酒田五法」のチャートパターン30種を、繰り返しクイズ形式で学習できます。相場の転換サインを素早く見抜く力を身につけることを目的としています。

## 機能

### クイズモード
- **上昇／下落**: チャートを見てその後の方向を当てる
- **パターン名4択**: ローソク足の形からパターン名を選ぶ
- **基本形 / 実戦**: 模式図チャートと実際の日本株市場チャートを切り替え
- **問題数**: 10問 / 30問 / 無制限

### 学習サポート
- **弱点強化モード**: 間違えたパターンが優先的に出題される（50問ミスで解放）
- **連続正解ストリーク**: 何問連続で正解できるかを記録
- **進捗バー**: クイズ中の進捗を視覚的に表示

### パターン図鑑
- 全30パターンを上昇・下落サインに分けて一覧表示
- 各パターンの模式図チャート・説明・実例チャートを確認できる
- 苦手なパターンには炎アイコンで表示

## 収録パターン（30種）

| 上昇サイン | 下落サイン |
|---|---|
| 赤三兵、明けの明星、陽のたすき | 三羽烏、宵の明星、陰のたすき |
| 包み足陽線、はらみ足陽線、切り込み線 | 包み足陰線、はらみ足陰線、かぶせ線 |
| 毛抜き底、最後の抱き線陰 | 毛抜き天井、最後の抱き線陽、行き詰まり線 |
| カラカサ、トンボ | 首吊り線、トンカチ、塔婆 |
| 上放れ並び赤、上放れ三手放れ寄せ線 | 上放れ並び黒、上放れ十字線 |
| 下放れ並び赤、下放れ十字線 | 下放れ二本の陰線、下放れ三手放れ寄せ線 |

## 技術スタック

- Swift / SwiftUI
- iOS 26.2+
- yfinance（クイズデータ生成、Pythonスクリプト）

## クイズデータの生成

`generate_quiz.py` を使って日本株の過去データから各パターン最大500件のチャートデータを生成します。

```bash
pip install yfinance pandas
python generate_quiz.py
```

生成した `quiz_data.json` を `SakataChartQuiz/` ディレクトリに配置します。
